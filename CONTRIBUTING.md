# Contributing

Thanks for considering a contribution to INDEXIO.

## Before you start

- Check existing issues to avoid duplicate work.
- For larger changes, open an issue first to discuss the approach.
- Keep the application dependency-free unless a dependency is justified.

## Development

```bash
php -S 127.0.0.1:8000
```

Then open <http://127.0.0.1:8000>.

## Pull requests

- Keep changes focused and explain the motivation.
- Test on desktop and mobile-sized screens.
- Verify all five language options.
- Check directory navigation, sorting, searching, and list/grid switching.
- Consider security and accessibility.
- Update the README or changelog when behavior changes.
