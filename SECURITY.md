# Security Policy

## Supported versions

Security fixes are intended for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue.
Contact the repository owner privately through the security reporting feature on GitHub,
if enabled. Include the affected version, impact, and reproducible steps.

## Deployment guidance

INDEXIO lists readable file and directory metadata. Restrict access with web-server
authentication or network controls if the content is private. The `noindex` directive
does not provide access control.
